## Normal KCNQ1 Function

KCNQ1 encodes the Kv7.1 voltage-gated potassium channel protein. In cardiac muscle cells, KCNQ1 contributes to the IKs potassium current, which helps with cardiac repolarization and normal electrical activity of the heart.

## Project Summary

This project investigates how the KCNQ1 c.5C>G mutation changes the predicted protein sequence and how the sequence change may relate to the molecular basis of Long QT Syndrome Type 1.
